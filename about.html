About Me

Developer, designer,
security learner

I'm Huzaifa Usman, a web developer based in Oman. I create modern, high-performing websites and I'm skilled in web design and WordPress. Over the last few years I've worked across custom front-ends, dynamic PHP applications and CMS platforms for clients.

My journey

From layouts to full builds

I started out designing clean website layouts and moved steadily into full development — first HTML, CSS and JavaScript, then PHP and MySQL for dynamic functionality, and WordPress for clients who need to manage their own content. Today I handle projects end to end: design, build, responsiveness, performance and handover.

How I work

Clean code, clear communication

Every project starts with the layout and the user, not the framework. I keep code organised and readable, test across screen sizes, and keep clients updated through the process. Pricing and scope stay transparent from the first message.
